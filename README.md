# 拾光吉他

一款面向零基础用户的移动端优先吉他学习应用：30 天建立基本演奏能力，并为年底完整舞台表演一首歌做准备。

## 本地预览

这是一个无构建步骤的静态站点。使用任意静态文件服务器打开仓库根目录即可，不要直接双击 HTML 文件进行音频测试。

## 部署

GitHub Pages 继续使用 `main` 分支根目录发布。不需要、也不应新增 Pages Actions。

## 数据

课程和考试进度保存在浏览器 `localStorage` 中；清除浏览器站点数据会一并清除学习记录。

完整产品结构与后续计划见 [PRODUCT_PLAN.md](PRODUCT_PLAN.md)。
